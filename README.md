💻 Featured project

Snip-Snap — UK Barbershop Discovery App

Collaborative university project · Python · Flask · JavaScript · HTML · CSS · PostgreSQL · Supabase

Snip-Snap is a full-stack web application designed to help users discover barbers and barbershops across the UK. Our team built features such as location-based discovery, search and filtering, an interactive map, user profiles, reviews and a barber dashboard.
